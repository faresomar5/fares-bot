# 🤖 بوت تيليجرام + واتساب (Multi-Device) — Baileys

مشروع كامل جاهز للتشغيل: بوت **تيليجرام** (Telegraf) يدير أرقام **واتساب** متعددة
عبر مكتبة **@whiskeysockets/baileys**، بربط **كود الاقتران** (8 أرقام) بدون QR،
لوحة أزرار تفاعلية، محرك تفاعل بشري على الحالات، ومحرك أوامر متقدم.

---

## ✨ المميزات

### 1. الربط بكود الاقتران (Pairing Code)
- المستخدم يرسل رقمه للبوت على تيليجرام → البوت يولّد **كود من 8 أرقام** ويُرسله له.
- الربط يتم عبر: واتساب ← الأجهزة المرتبطة ← **الربط برقم الهاتف**.
- لا حاجة لـ QR Code إطلاقاً (مناسب للسيرفرات بدون واجهة).
- الجلسة تُحفظ على القرص، فإعادة التشغيل لا تطلب كوداً جديداً.

### 2. لوحة أزرار تفاعلية — أكثر من 15 زر إدارة
لوحة `/start` تحتوي **24 زر إدارة**:

| الزر | الوظيفة |
|---|---|
| 🔗 ربط رقم جديد | توليد كود اقتران لرقم جديد |
| ❌ فصل الرقم | فصل الرقم مع الحفاظ على الجلسة |
| 📊 حالة الحساب | تفاصيل كاملة عن الرقم والحالة |
| 🟢 تفاعل الحالات | تشغيل/إيقاف التفاعل التلقائي |
| 😀 إيموجياتي | عرض الإيموجيات وأزرار حذف سريع |
| ➕ إضافة إيموجي | إضافة إيموجيات بلا حدود |
| 🗑 حذف إيموجي | حذف إيموجي بالضغط عليه |
| ♻️ إعادة تعيين | استعادة الإيموجيات الافتراضية |
| 💚 القلب الأخضر | تشغيل/إيقاف القلب الأخضر |
| 👀 مشاهدة الحالة أولاً | سلوك بشري طبيعي قبل التفاعل |
| ⏱ تأخير التفاعل | ضبط الثواني قبل التفاعل |
| 🛡 وضع الحماية | تقييد السرعة + قائمة حظر |
| 🚫 قائمة الحظر | عرض المحظورين |
| 👥 إدارة المجموعات | قائمة المجموعات، قفل، فتح |
| 🤖 الردود الآلية | إدارة ردود كلمة → رد |
| 📥 تحميل الوسائط | تحميل من 15 منصة |
| 🧹 تنظيف الذاكرة | تشغيل GC وتحرير RAM |
| 📈 إحصائيات | إحصائيات التفاعل |
| 🔔 ساعات الهدوء | إيقاف التفاعل في وقت محدد |
| 📢 رسالة جماعية | إرسال لكل جهات الاتصال |
| 🧪 فحص الاتصال | قياس زمن الاستجابة |
| ⚙️ الإعدادات | لوحة إعدادات متقدمة |
| 📜 قائمة الأوامر | كل الأوامر حسب الفئة |
| ℹ️ حول البوت | معلومات النظام |

### 3. إيموجيات تفاعل بلا حدود
- كل مستخدم له قائمة إيموجيات خاصة محفوظة في `data/db.json`.
- إضافة/حذف غير محدود عددياً، عبر الأزرار أو الأوامر (`/addemoji` `/delemoji`).
- يمكن إضافة عدة إيموجيات دفعة واحدة: `😀 🔥 💯`.

### 4. تفاعل بشري حقيقي على الحالات (Human-like)
عند نشر أي حالة جديدة من جهات الاتصال، يقوم الرقم المربوط بـ:
1. **مشاهدة الحالة** أولاً (`readMessages`) — لتُسجَّل كمشاهدة طبيعية 👀
2. **انتظار ثوانٍ عشوائية** (قابل للضبط، افتراضياً 4–12 ثانية) + ضجيج عشوائي بالملي ثانية
3. **إرسال الإيموجي المخصص** على الحالة (`react` إلى `status@broadcast` مع `statusJidList`)
4. **إرسال القلب الأخضر 💚** لمحاكاة السلوك البشري

> ⚠️ **ملاحظة تقنية صريحة:** واتساب يسمح بتفاعل واحد فقط لكل رسالة/حالة، لذا عند إرسال
> الإيموجي ثم القلب الأخضر، يبقى **الأخير** ظاهراً. يمكن عكس الترتيب من الإعدادات
> (`عكس ترتيب التفاعل`). البوت يُنفّذ التسلسل كاملاً كما هو مطلوب تقنياً.

### 5. محرك الأوامر المتقدم
- نظام **سجل أوامر** (Registry) مع فئات ومرادفات عربية/إنجليزية.
- أوامر حقيقية التنفيذ: أدوات النص، الترميز، التجزئة، الحسابات، الترفيه، إسلاميات، أدوات ويب (ويكيبيديا/طقس/عملات/IP/QR)، المجموعات، الوسائط.
- أوامر تحتاج مكتبات إضافية (OCR، TTS، إزالة الخلفية، PDF) موجودة في السجل وتُعلم المستخدم بما يلزم لتفعيلها بوضوح — **بدون أي واجهة وهمية**.
- عدد الأوامر المميزة (distinct) يُطبع فعلياً عند التشغيل؛ مع المرادفات يتضاعف العدد.

### 6. تحسين أداء السيرفر (لـ 100 رقم)
- `makeCacheableSignalKeyStore` لتقليل قراءة/كتابة المفاتيح على القرص.
- `syncFullHistory: false` + `markOnlineOnConnect: false` + عدم تحميل مخزن رسائل.
- `--expose-gc --max-old-space-size=450` مع **حارس ذاكرة** دوري (GC + تفريغ كاشات + تنظيف مجلد tmp).
- إعادة اتصال تلقائية بـ **backoff** أسّي (حتى 60 ثانية) دون انهيار العملية.
- استئناف الجلسات المحفوظة **تدريجياً** عند الإقلاع لمنع ارتفاع الذاكرة دفعة واحدة.
- حد أقصى قابل للضبط `MAX_SESSIONS` (افتراضياً 100).

## 🚀 التشغيل

### المتطلبات
- **Node.js 20** أو أحدث (`node -v`)
- توكن بوت من [@BotFather](https://t.me/BotFather)
- `yt-dlp` لميزات التحميل (اختياري لكن مُستحسن)

### الخطوات
```bash
# 1) تثبيت الاعتماديات
npm install

# 2) تجهيز ملف البيئة
cp .env.example .env
nano .env          # ضع BOT_TOKEN وأضف OWNER_ID

# 3) تثبيت yt-dlp (اختياري — لميزات التحميل)
pip install -U yt-dlp
# أو: sudo apt install -y yt-dlp ffmpeg

# 4) التشغيل
npm start
```

### سكربتات جاهزة
| الأمر | الوظيفة |
|---|---|
| `npm start` | تشغيل كامل مع `--expose-gc --max-old-space-size=450` |
| `npm run start:lite` | تشغيل موفّر للذاكرة (256MB) — للأجهزة الضعيفة جداً |
| `npm run dev` | تشغيل مع إعادة تحميل تلقائية |
| `npm run check` | فحص صحة كل ملفات JS |
| `npm run count` | طباعة عدد الأوامر المسجّلة |

### طريقة الاستخدام
1. افتح البوت على تيليجرام وأرسل `/start`.
2. اضغط **🔗 ربط رقم جديد** وأرسل رقمك بصيغة دولية بدون `+` (مثال: `966501234567`).
3. سيصلك **كود من 8 أرقام** — أدخله في واتساب: الأجهزة المرتبطة ← الربط برقم الهاتف.
4. بعد الربط، سيبدأ التفاعل التلقائي على الحالات حسب إعداداتك.

## ⚙️ متغيّرات البيئة المهمة

| المتغير | الوصف | الافتراضي |
|---|---|---|
| `BOT_TOKEN` | توكن بوت تيليجرام | **إلزامي** |
| `OWNER_ID` | آيدي المالك (للأوامر الإدارية) | — |
| `MAX_SESSIONS` | الحد الأقصى للأرقام المتصلة | `100` |
| `GC_INTERVAL_MS` | دورية فحص الذاكرة | `60000` |
| `MEM_LIMIT_MB` | حد الهيب الذي يُفعّل التنظيف | `400` |
| `DEFAULT_REACT_DELAY_MIN/MAX` | تأخير التفاعل الافتراضي | `4` / `12` |

## ☁️ النشر

**VPS / Ubuntu**
```bash
sudo apt update && sudo apt install -y nodejs npm ffmpeg python3-pip
pip install -U yt-dlp
npm install
npm i -g pm2
pm2 start bot.js --name tgwa --node-args="--expose-gc --max-old-space-size=450"
pm2 save && pm2 startup
```

**Koyeb / Railway / Render** — استخدم أمر البناء `npm install` وأمر التشغيل:
```
node --expose-gc --max-old-space-size=450 bot.js
```
> على المنصات ذات القرص المؤقت، اضبط `SESSION_DIR` و`DATA_DIR` على وحدة تخزين دائمة
> (Volume) وإلا ستُفقد الجلسات عند كل إعادة نشر.

## ⚠️ تنبيهات مهمة (اقرأها)

- هذا المشروع يستخدم واتساب عبر **مكتبة غير رسمية** (Baileys). لا يوجد ضمان من واتساب،
  وقد يؤدي الاستخدام المكثّف أو الآلي إلى **تقييد مؤقت أو حظر دائم للرقم**. لا يمكن
  وصف أي إعداد بأنه «آمن 100%»؛ الميزات البشرية هنا (مشاهدة + تأخير عشوائي) تقلّل
  الاحتمال فقط ولا تلغيه.
- استخدم أرقاماً يمكنك تحمّل فقدانها، ولا تستخدم رقمك الشخصي الأساسي.
- حدود تيليجرام: حجم ملف التحميل الأقصى عبر البوت ~50MB (يعتمد على حد Telegram Bot API).
- أمر «رسالة جماعية» يجب استخدامه بحذر (يُنصح بحد 50 رسالة لكل دفعة).
- الفشل الشائع `Connection Closed` عند طلب الكود يحدث إذا طُلب الكود قبل جهوزية السوكيت؛
  الكود هنا يطلبه بعد حدث `qr` في `connection.update` (الطريقة الموصى بها).
