# 🤖 بوت تيليجرام + واتساب (Multi-Device) — Baileys

مشروع كامل جاهز للتشغيل: بوت **تيليجرام** (Telegraf) يدير أرقام **واتساب** متعددة
عبر مكتبة **@whiskeysockets/baileys**، بربط **كود الاقتران** (8 أرقام) بدون QR،
لوحة أزرار تفاعلية، محرك تفاعل بشري على الحالات، ومحرك أوامر متقدم.

---

## 🆕 ما الجديد في الإصدار 1.3.0

### 1) إصلاح التحميل من جميع المنصات (تيك توك وغيرها)
- **إصلاح جذري لملف `package.json`** — كان غير صالح كـ JSON (فاصلة ناقصة في قسم `scripts`)
  وهذا يُفشل `npm install` بالكامل، وبالتالي لا تُثبَّت الاعتماديات ولا يُثبَّت `yt-dlp`،
  فيظهر الخطأ: `لم يتم العثور على yt-dlp ... pip install -U yt-dlp`.
- **اكتشاف yt-dlp بعدة طرق**: ملف محلي داخل `data/bin` ← متغيّر البيئة ← `PATH` ←
  `python3 -m yt_dlp` ← `python -m yt_dlp`. لا يُخزَّن نتيجة فاشلة بعد الآن.
- **تثبيت تلقائي أقوى**: `pip` مع `--user` و`--break-system-packages` (لازم على
  Debian/Ubuntu الحديثة)، وإن فشل كل شيء يُنزَّل الملف التنفيذي المستقل من GitHub.
- **6 استراتيجيات إعادة محاولة** لكل رابط (بدل محاولة واحدة):
  وسائط تيك توك، إنستجرام/فيسبوك، عميل يوتيوب، انتحال المتصفح، IPv4 بدون كاش...
- **بدائل مباشرة** عند فشل yt-dlp: تيك توك عبر `tikwm` (بدون علامة مائية)
  وتويتر/X عبر `fxtwitter`.
- **دعم ملف كوكيز** `data/cookies.txt` للمحتوى الذي يطلب تسجيل دخول، ورسالة خطأ
  واضحة تدلّك عليه بدل «خطأ غير معروف».
- **اكتشاف ffmpeg** لدمج الفيديو مع الصوت والتحويل إلى MP3، ومع fallback بجودة
  أحادية الملف عند غيابه.
- **إرسال صحيح للوسائط**: الصور تُرسل كصور، والصوت كصوت، والباقي كفيديو (سابقاً
  كان كل شيء يُرسل كفيديو حتى الصور).

### 2) الجلسات في مجلد دائم — لا تُحذف بإعادة تشغيل السيرفر
- البوت يكتشف **وحدة تخزين دائمة** تلقائياً (`/data`, `/mnt/data`, `/var/data`,
  `/opt/data`, `/persistent`, `/storage`, `/app/data`) وينقل الجلسات إليها.
- يحفظ المسار في ملف علامة `.persist-root` فيعمل نفس المجلد في كل تشغيل.
- **ترحيل تلقائي** للجلسات القديمة من `./sessions` إلى المجلد الدائم + **رابط رمزي**
  للتوافق مع أي إعداد قديم.
- يمكن تحديد المسار صراحةً بمتغيّر `PERSIST_ROOT` أو بمسار مطلق في
  `SESSION_DIR` / `DATA_DIR`.

### 3) إيقاف رسالة «تم ربط الرقم بنجاح» عند إعادة التشغيل
- الرسالة **متوقفة افتراضياً** (كانت تُرسل عند كل إقلاع لكل جلسة).
- للتفعيل: ⚙️ الإعدادات ← **🔕 رسالة الربط عند الإقلاع** (أو `notifyOnConnect`).

### 4) إيقاف رسالة «نُفّذ أمر واتساب» داخل بوت تيليجرام
- الإشعار **متوقف افتراضياً** ولا يصل إلى تيليجرام عند تنفيذ أي أمر من واتساب.
- للتفعيل: ⚙️ الإعدادات ← **⚡ إشعار أوامر واتساب**.

### 5) إرسال المحذوفات والحالات والعرض لمرة واحدة إلى **خاص الرقم المربوط** (ولمرة واحدة)
- الوجهة الافتراضية الآن هي **محادثة الرقم المربوط نفسه داخل واتساب** — لا بوت تيليجرام.
- خيار «**مرة واحدة فقط**» مفعّل افتراضياً: لا تكرار لنفس الحدث أبداً (سابقاً كانت
  تُرسل نسختان: واحدة من `guard.js` وأخرى من `commands.js`).
- يمكن التحويل إلى تيليجرام أو للاثنين من: ⚙️ الإعدادات ← **📍 وجهة التنبيهات**.

### 6) إرسال **رقم صاحب الحدث الحقيقي** بدل الآيدي
- استخراج الرقم الفعلي يعتمد الآن الترتيب الصحيح:
  `participantAlt` → `remoteJidAlt` → `senderPn/participantPn` → `participant` → `remoteJid`
  (بدل رأس قائمة خاطئ كان يُعيد الأيدي أو قيمة غير معرّفة).
- الرقم يُرسل بصيغة دولية نظيفة (`+9665xxxxxxxx`) مع تحقق من صحته (8–15 خانة)،
  وإن تعذّر الوصول للرقم تظهر «غير معروف» بوضوح بدل قيمة تالفة.
- يُطبَّق على: حذف الرسائل لدى الجميع، حذف الحالات، والعرض لمرة واحدة.

## ✨ المميزات الأساسية

### 1. الربط بكود الاقتران (Pairing Code)
- المستخدم يرسل رقمه للبوت على تيليجرام → البوت يولّد **كود من 8 أرقام** ويُرسله له.
- الربط عبر: واتساب ← الأجهزة المرتبطة ← **الربط برقم الهاتف**. لا QR إطلاقاً.
- الجلسة تُحفظ على القرص الدائم، فإعادة التشغيل لا تطلب كوداً جديداً.

### 2. لوحة أزرار تفاعلية — 24 زر إدارة
ربط رقم جديد، فصل الرقم، حالة الحساب، تفاعل الحالات، إيموجياتي، إضافة/حذف إيموجي،
إعادة تعيين، القلب الأخضر، مشاهدة الحالة أولاً، تأخير التفاعل، وضع الحماية،
قائمة الحظر، إدارة المجموعات، الردود الآلية، تحميل الوسائط، تنظيف الذاكرة،
الإحصائيات، ساعات الهدوء، رسالة جماعية، فحص الاتصال، الإعدادات، قائمة الأوامر،
حول البوت.

### 3. إيموجيات تفاعل بلا حدود
قائمة إيموجيات خاصة لكل مستخدم محفوظة في `data/db.json`، إضافة/حذف غير محدود
عبر الأزرار أو الأوامر (`/addemoji` `/delemoji`)، وإضافة عدة إيموجيات دفعة واحدة.

### 4. تفاعل بشري حقيقي على الحالات
مشاهدة الحالة أولاً (`readMessages`) ← تأخير عشوائي قابل للضبط + ضجيج عشوائي ←
إرسال الإيموجي المخصص ← القلب الأخضر 💚.

> ⚠️ واتساب يسمح بتفاعل واحد فقط لكل حالة؛ لذا يبقى **الأخير** ظاهراً.
> يمكن عكس الترتيب من الإعدادات (`عكس ترتيب التفاعل`).

### 5. محرك الأوامر المتقدم
سجل أوامر (Registry) مع فئات ومرادفات عربية/إنجليزية، أوامر حقيقية التنفيذ
(نص، ترميز، تجزئة، حسابات، ترفيه، إسلاميات، أدوات ويب، مجموعات، وسائط، تحميل).

### 6. أوامر الرقم المربوط (داخل واتساب)
| الأمر | الوظيفة |
|---|---|
| `.الاوامر` | عرض جميع الأوامر المتاحة |
| `.الحذف` | تشغيل/إيقاف كشف حذف الرسائل «لدى الجميع» |
| `.الحالات` | تشغيل/إيقاف عدم حذف حالات الواتساب |
| `.كشف` | تشغيل/إيقاف كشف «العرض لمرة واحدة» |
| `.تنبيه` | تشغيل/إيقاف كل التنبيهات دفعة واحدة |

كل الأوامر تعمل بالبادئات: `.` و `/` و `!` و `#`، ويمكن التحكم بها من أزرار تيليجرام.

### 7. تحسين أداء السيرفر (لـ 100 رقم)
`makeCacheableSignalKeyStore`، `syncFullHistory: false`، حارس ذاكرة دوري
(GC + تفريغ كاشات + تنظيف tmp)، إعادة اتصال تلقائية بـ backoff أسّي،
واستئناف الجلسات المحفوظة تدريجياً عند الإقلاع.

## 🚀 التشغيل

### المتطلبات
- **Node.js 20** أو أحدث (`node -v`)
- توكن بوت من [@BotFather](https://t.me/BotFather)
- `yt-dlp` + `ffmpeg` لميزات التحميل (البوت يحاول تثبيت yt-dlp تلقائياً)

### الخطوات
```bash
# 1) تثبيت الاعتماديات
npm install

# 2) تجهيز ملف البيئة
cp .env.example .env
nano .env          # ضع BOT_TOKEN وأضف OWNER_ID

# 3) تثبيت أدوات التحميل (اختياري لكن مُستحسن)
python3 -m pip install -U --break-system-packages yt-dlp
sudo apt install -y ffmpeg

# 4) التشغيل
npm start
```

### سكربتات جاهزة
| الأمر | الوظيفة |
|---|---|
| `npm start` | تشغيل كامل مع `--expose-gc --max-old-space-size=450` |
| `npm run start:lite` | تشغيل موفّر للذاكرة (256MB) |
| `npm run dev` | تشغيل مع إعادة تحميل تلقائية |
| `npm run check` | فحص صحة كل ملفات JS |
| `npm run setup` | تثبيت yt-dlp يدوياً |
| `npm run count` | طباعة عدد الأوامر المسجّلة |

### طريقة الاستخدام
1. افتح البوت على تيليجرام وأرسل `/start`.
2. اضغط **🔗 ربط رقم جديد** وأرسل رقمك بصيغة دولية بدون `+` (مثال: `966501234567`).
3. سيصلك **كود من 8 أرقام** — أدخله في واتساب: الأجهزة المرتبطة ← الربط برقم الهاتف.
4. بعد الربط، سيبدأ التفاعل التلقائي على الحالات حسب إعداداتك.

## ☁️ النشر مع جلسات دائمة

**VPS / Ubuntu**
```bash
sudo apt update && sudo apt install -y nodejs npm ffmpeg python3-pip
python3 -m pip install -U --break-system-packages yt-dlp
npm install
npm i -g pm2
pm2 start bot.js --name tgwa --node-args="--expose-gc --max-old-space-size=450"
pm2 save && pm2 startup
```

**Koyeb / Railway / Render / Fly.io**
- أمر البناء: `npm install`
- أمر التشغيل: `node --expose-gc --max-old-space-size=450 bot.js`
- **مهم**: اربط **وحدة تخزين دائمة (Volume)** على المسار `/data` — سيكتشفها البوت
  تلقائياً ويحفظ فيها الجلسات، فلا تُفقد عند إعادة النشر.
- إن كانت منصتك تستخدم مساراً مختلفاً، اضبط `PERSIST_ROOT` على مسار الوحدة.

## ⚙️ متغيّرات البيئة المهمة

| المتغير | الوصف | الافتراضي |
|---|---|---|
| `BOT_TOKEN` | توكن بوت تيليجرام | **إلزامي** |
| `OWNER_ID` | آيدي المالك | — |
| `PERSIST_ROOT` | مسار التخزين الدائم | يُكتشف تلقائياً |
| `SESSION_DIR` / `DATA_DIR` | مسار مطلق للجلسات/البيانات | داخل التخزين الدائم |
| `ALERTS_TO` | وجهة التنبيهات: `whatsapp`/`telegram`/`both` | `whatsapp` |
| `MAX_SESSIONS` | الحد الأقصى للأرقام المتصلة | `100` |
| `COOKIES_FILE` | ملف كوكيز Netscape للتحميل المحمي | `data/cookies.txt` |
| `MEM_LIMIT_MB` | حد الهيب الذي يُفعّل التنظيف | `400` |
| `LOG_LEVEL` | مستوى اللوجات | `silent` |

## ⚠️ تنبيهات مهمة

- المشروع يستخدم واتساب عبر **مكتبة غير رسمية** (Baileys)؛ لا ضمان من واتساب،
  وقد يؤدي الاستخدام المكثّف أو الآلي إلى **تقييد مؤقت أو حظر دائم للرقم**.
  الميزات البشرية (مشاهدة + تأخير عشوائي) تقلّل الاحتمال فقط ولا تلغيه.
- استخدم أرقاماً يمكنك تحمّل فقدانها، ولا تستخدم رقمك الشخصي الأساسي.
- حد تيليجرام لرفع الملفات عبر البوت ~50MB؛ للفيديوهات الأكبر اختر جودة أقل (360p).
- الفشل `Connection Closed` عند طلب الكود يحدث إذا طُلب قبل جهوزية السوكيت؛
  الكود هنا يُطلب بعد حدث `qr` في `connection.update` (الطريقة الموصى بها).
